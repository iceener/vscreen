# Outcome

`vscreen` installs as a signed bundle (`~/Applications/vscreen.app`, `com.overment.vscreen`, hardened runtime, stable self-signed certificate in a dedicated keychain) with `~/.local/bin/vscreen` linked to it; every command runs as its own TCC-responsible process, so the Accessibility and Screen Recording grants belong to vscreen and survive rebuilds. `display start|stop|status` holds a 1920x1200 HiDPI `CGVirtualDisplay` in a daemon, placed touching the main display only at its bottom-right corner; the private API works on macOS 26.5.2. Review 1 (accept with fixes) was repaired in 35d9860/f15579b and merged: start/stop lock and single-daemon lock, `--origin 0,0` refused, post-placement and watchdog checks that the user's display stays main and unmirrored, daemon identity by start time, daemon failure codes, responsibility check replacing the env guard. Never exercised live by design: the mirror/main recovery paths (testing them means mirroring the user's screen). Incident on record: during development a bad display identity mirrored the XDR twice for 2–4 s; the fixed physical size and per-mode serial prevent it.
